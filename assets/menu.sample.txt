# 自定义菜单模板
# 把这个文件改名为 menu.txt，放在项目根目录（开发时）或 wte.exe 同目录（发布版），
# 也可以点程序里的「生成菜单模板」自动创建。
#
# 格式（用 | 分隔，一行一道菜）：
# 名称 | 口味(甜/咸/皆) | 汤水(汤/干/皆) | 主食(饭/面/其他) | 辣度(0-2) | 餐段(早/午/晚/皆) | 备注
#
# 说明：
#   - 以 # 或 // 开头的行是注释；空行会被忽略
#   - 餐段：写「早」只在早饭出现，写「晚」只在晚饭出现，写「皆」表示全天
#   - 主食必须是 饭 / 面 / 其他，不能写「皆」
#   - 不显示价格；点外卖时请以平台实际价格为准
#   - 和内置题库同名的菜会覆盖内置条目（可以改口味、餐段、备注）
#
# 示例：
黄焖鸡米饭|咸|干|饭|1|皆|我家楼下这家微辣刚好
八宝粥|甜|汤|饭|0|早|甜口暖胃
部队锅|咸|汤|其他|1|晚|一个人也能吃
